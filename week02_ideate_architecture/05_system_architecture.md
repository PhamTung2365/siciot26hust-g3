# 5. System Architecture

## Kiến trúc end-to-end
```text
Physical World
      ↓
Sensor
      ↓
Edge Device
      ↓
Network
      ↓
Backend / IoT Platform
      ↓
Database
      ↓
Application / Dashboard
      ↓
User
```

## Nếu có điều khiển
```text
User / Rule
    ↓
Command
    ↓
Network
    ↓
Edge
    ↓
Actuator
    ↓
Physical World
```
